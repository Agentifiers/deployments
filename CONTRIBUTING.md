# Contributing

Deployments is source available. The platform is licensed under the Functional Source License
(`FSL-1.1-ALv2`) and the SDK and CLI packages under MIT, as the License section of
[`README.md`](README.md#license) lists. It is not an open source project, and this repository does
not accept pull requests; pull requests are turned off.

## Issues

Open an issue to report a bug or a documentation error, or to request a feature. A useful bug
report names the commit or package version, what you ran, what you expected, and what happened,
with logs or a minimal reproduction.

The maintainers write, review, and ship every change. When an issue leads to a change, a
maintainer makes it. If you have a fix in mind, describe the problem and the change in the issue
instead of sending code.

## Security

Do not report a suspected vulnerability in a public issue. Follow [`SECURITY.md`](SECURITY.md) to
report it privately.

## Building from source

See the Development section of [`README.md`](README.md#development) for prerequisites and the
commands that build and test the repository.
